## 🔒 The Flora Philosophy: 100% Sovereign Privacy

Most mainstream menstrual and fertility tracking apps collect personal, intimate health metrics, monetize your data, or upload it to cloud servers.

**Flora is different:**
- **Zero Cloud Servers**: No accounts, logins, passwords, or emails.
- **Zero Analytics & Trackers**: No third-party SDKs, telemetry, cookies, or remote surveillance.
- **100% Offline Storage**: All cycle dates, symptoms, and settings are saved exclusively on your device (`localStorage` / local sandbox).
- **Zero Vendor Lock-In**: Export your entire dataset anytime as a human-readable text file (`.txt`) and restore it seamlessly on any new device.

## ✨ Features

### 📅 Intuitive Calendar & 1-Tap Quick Tick
- **⚡ 1-Tap Quick Tick Mode**: Toggle consecutive period bleeding days instantly with a single touch.
- **Smooth Navigation**: Multi-month continuous view and month-by-month pagination.
- **Crystal-Clear Visual Coding**:
  - <span style="color:#be185d;">■</span> **Dark Pink** (`#be185d`): Logged period bleeding days.
  - <span style="color:#f472b6;">⬚</span> **Dashed Pink**: Projected future period days.
  - <span style="color:#15803d;">■</span> **Bottle Green** (`#15803d`): Fertile window (higher probability of conception).
  - <span style="color:#064e3b;">★</span> **Bold Deep Bottle Green** (`#064e3b` with `★`): **Peak Ovulation Day**.
  - <span style="color:#64748b;">■</span> **Slate Gray** (`#64748b`): Regular non-fertile days.

### 🔮 Clinically Grounded Cycle Engine
- **Clinical Luteal Phase Model**: Predicts ovulation approximately 14 days before your projected next cycle start.
- **Historical Statistical Rolling Averages**: Automatically learns your unique cycle length and bleeding duration from past logged cycles.
- **Fertile Window Projection**: Calculates a 6-day fertile window (5 days prior to ovulation + peak ovulation day).
- **6-Cycle Long-Range Projections**: Accurately projects up to 6+ cycles ahead for travel, events, and family planning.
- **Delay & Late Cycle Detection**: Dynamically calculates overdue days if your cycle exceeds expected intervals.
- **Daily Contextual Insights**: Phase-specific medical and wellness guidance across menstrual, follicular, fertile, ovulation, and luteal phases.

### 📝 Comprehensive Symptoms & Flow Logging
- **Flow Levels**: Spotting, Light, Medium, Heavy.
- **Symptom Tracker**: Cramps, Headache, Bloating, Tender Breasts, Acne, Fatigue, Mood changes.
- **Day Notes**: Freeform personal notes per calendar day.

### 🌐 Bilingual Interface
- Full instant toggle between **English** and **Polski (Polish)** with complete localized terminology and day/month formatting.

### 💾 Safe Backup & Seamless Migration
- **Instant Export**: Download `.txt` backups to your phone storage or share via system share sheets.
- **Instant Restore**: Copy-paste date text or upload your `.txt` backup file to restore your entire cycle history in milliseconds.

## 🚀 Getting Started (Development)

### Prerequisites
- [Node.js](https://nodejs.org/) (v20+ recommended)
- `npm` (v10+)

### 1. Clone & Install
```bash
git clone https://github.com/styliana/Flora.git
cd Flora
npm install
```

### 2. Start the Local Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173/`.

### 3. Test on Mobile Over Local Wi-Fi
```bash
npm run dev -- --host
```
Open the provided Network URL (e.g. `http://192.168.x.x:5173`) on your smartphone's browser.

## 📦 Building Native Mobile Apps

### 🤖 Android (APK)
Flora includes a ready-to-run npm script that builds web assets, syncs Capacitor, and compiles a debug APK via Gradle:

```bash
npm run build:apk
```
The compiled APK will be output as `flo.apk` in the repository root.

For detailed manual instructions using Android Studio, see [`README_APK.md`](README_APK.md).

### 🍎 iOS (IPA)
Flora is fully configured with Capacitor 8 and Swift 6 for iOS:

1. **Local iOS development with Xcode**:
   ```bash
   npm run build
   npx cap sync ios
   npx cap open ios
   ```
2. **Automated GitHub Actions CI**:
   Every push to `main` triggers `.github/workflows/build-ios.yml` running on `macos-15` with Xcode 16 to build and bundle an unsigned `Flora.ipa` artifact.

### 🌐 Progressive Web App (PWA)
Flora includes a standalone `public/manifest.json` with mobile viewport optimizations. Users can open the web app in Safari (iOS) or Chrome (Android) and tap **"Add to Home Screen"** to install it as an app without an app store.
